# 🚀 Estudos de React

Este repositório foi criado com o objetivo de estudar e praticar o desenvolvimento de aplicações utilizando **React.js**.

## 📚 Sobre o projeto

O projeto reúne exemplos, exercícios e conceitos fundamentais do React, desenvolvidos ao longo do processo de aprendizagem.

Entre os tópicos estudados estão:

- Componentes
- Props
- State
- Eventos
- Renderização condicional
- Renderização de listas
- Hooks
- Manipulação de formulários
- Estruturação de aplicações React

## 🛠️ Tecnologias utilizadas

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
